Click the squares, press Play, and learn how HTML, CSS and JavaScript work together.

🎓 How this website works

This little application uses all three major web technologies:

  • HTML → creates the buttons and page structure.
  • CSS → makes everything look nice.
  • JavaScript → makes the drum machine actually work.

1. HTML — the structure

HTML is like the skeleton of your website.

For example:

<button>Play</button>

creates a button.

2. CSS — the appearance

CSS tells the browser how an HTML element should look.

For example:

background: #22c55e;

changes the background color of an element.

3. JavaScript — the brain 🧠

JavaScript can find HTML elements and change them.

For example:

document.getElementById("playButton")

finds the Play button.

💡 Try this: Open this file in a code editor. Find background: #facc15; and change the color. Save the file and refresh the browser.
